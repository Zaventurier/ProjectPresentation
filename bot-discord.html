Application Discord

Un projet communautaire développé en JavaScript avec Discord.js et Node.js

🧠 Fonctionnalités principales

  • 💬 Commandes slash personnalisées
  • 📅 Défis mensuels avec rôle à la clé
  • 🧩 Énigmes à résoudre via des commandes dédiées
  • 🎁 Système d’événements aléatoires (bonus/malus)
  • 🎲 Système de probabilité
  • 🛠️ Interface de modération avec commandes staff

⚙️ Technologies utilisées

  • Node.js
  • Discord.js v14
  • JSON pour la configuration et les données
